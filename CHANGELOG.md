# Changelog

All notable user-facing changes to BumpCompanion will be documented in this file.

## 1.0.0 - 2026-08-07

### Added

- Initial public release of BumpCompanion.
- User-started road bump detection using phone motion sensors and driving context.
- Saved bump locations, review workflow, and approach warnings.
- Sensitivity, warning-output, units, calibration, and optional route-history settings.
- Local drive history and BumpCompanion bump-list import/export.
